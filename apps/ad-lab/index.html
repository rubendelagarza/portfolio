Lab: Active Directory onboarding, offboarding and cleanup

Work a morning's queue of identity tickets with the ActiveDirectory PowerShell module: a new hire, a locked-out user, a leaver, stale accounts and a privilege problem hiding in nested groups.

Intermediate~12 minPowerShell (ActiveDirectory)3 randomized ticket queues
What this demonstrates: the Active Directory administration I did as an IT Support Analyst and escalation point at TCS: naming standards, least-privilege group access, safe offboarding and directory hygiene.

Objectives

    Contoso account standard

    sAMAccountName
    first initial + last name, lowercase (e.g. jperez). If taken, append 2, 3…
    UPN
    first.last@contoso.com
    Name / DisplayName
    First Last
    Location
    OU=<Department>,OU=Users,OU=Contoso,DC=contoso,DC=local
    New accounts
    Enabled, temporary password, must change at next logon; Department and Title set
    Leavers
    Disable, move to OU=Disabled Users,OU=Contoso; remove groups; never delete (mailbox and audit retention)
