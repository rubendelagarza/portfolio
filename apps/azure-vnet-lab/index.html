Lab: Azure VNet, NSG and a Linux VM

Stand up a small web server in Azure with the CLI: resource group under subscription policy, a virtual network and subnet, a network security group that only opens what's needed, and an Ubuntu VM with SSH keys. Watch for the defaults az vm create adds behind your back.

Fundamentals+~10 minAzure CLI3 randomized starting points
What this demonstrates: Azure Fundamentals in practice: resource groups and regions, tags and Azure Policy, VNets and subnets, NSG rule priority and default rules, subnet vs NIC NSGs, and VM authentication.
