Lab: Repair a broken VPC peering

An app in one VPC can't reach an API in a peered VPC. Diagnose it from Cloud Shell, fix it without weakening security, and prove the fix.

Intermediate~8 mingcloud3 randomized faults
What this demonstrates: the Google Cloud networking cases I resolved at Infosys: peering state, firewall evaluation order, and using Connectivity Tests to prove where a packet dies.

"Our app on app-1 (prod-vpc) can't call the orders API on api-1 (shared-vpc) over HTTPS. We set up peering last week. Everything is in project contoso-prod."
