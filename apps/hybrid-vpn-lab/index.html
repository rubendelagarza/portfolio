Lab: Connect an on-prem data center with HA VPN and BGP

Build a 99.99%-SLA HA VPN between Google Cloud and the Monterrey data center. Read the on-prem router config, match it exactly, steer traffic with BGP, then pull a tunnel and watch it fail over.

Advanced~15 mingcloud · BGP3 randomized router configs
What this demonstrates: hybrid connectivity from on-premises to Google Cloud with HA VPN, with redundancy and failover through Cloud Router and BGP. The same Cloud Router and BGP model applies to Dedicated and Partner Interconnect.
