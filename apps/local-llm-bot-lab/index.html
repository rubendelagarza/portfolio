Lab: Local LLM + Telegram renewal bot

Run Qwen3.5 4B on an office Linux server with Ollama, then deploy a Telegram bot that reminds an insurance agent which policies are due for renewal, written by the local model. No customer data leaves the building.

Intermediate–Advanced~20 minOllama · Qwen3.5 · Python · Telegram · systemd3 randomized starting points
What this demonstrates: self-hosting a small open-weight model (Ollama, Qwen3.5 4B, CPU-only sizing), keeping its API private, Python deployment on Ubuntu 24.04 (venv, PEP 668), secrets and a dedicated service user, a Telegram bot created with BotFather, and debugging the glue code between a database, a local LLM and a chat app.
Telegram · Andrea Leal's phone · simulation

Work order

Andrea Leal, an independent insurance agent, wants a Telegram assistant that tells her every morning which policies are due for renewal, and answers /polizas on demand. Policy data must stay in the office, so the language model runs locally on srv-ia01. You're in an SSH session as ruben.

Server
srv-ia01 · Ubuntu 24.04 · 4 vCPU · 8 GB RAM · no GPU
Model
qwen3.5:4b (Ollama, ~3.4 GB)
Bot code
/opt/polizabot (read README.md)
Rule
Remind 30 days ahead, every day at 09:00 Mexico City time
