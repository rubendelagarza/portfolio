Lab: Harden a new client's Microsoft 365 tenant

A freshly migrated tenant still has permissive defaults. Use Exchange Online and Microsoft Teams PowerShell to lock down meetings and guest access, warn users about external mail, set up a shared mailbox and fix a mailbox that's about to stop receiving mail.

Intermediate~10 minPowerShell (EXO + Teams)3 randomized tenants
What this demonstrates: the Microsoft 365 configuration work I do as a Senior Technical Consultant at Perficient, in the post-migration phase: Outlook/Exchange and Teams settings, permissions, and storage, done through PowerShell so it's repeatable.

Client brief: Contoso Ltd

Migration finished last week. Before go-live sign-off, the CISO wants the post-migration hardening checklist done. You're connected to Exchange Online and Microsoft Teams PowerShell as a Global Administrator.
