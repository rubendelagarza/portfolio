Lab: SQLite database and Sign in with Google

The app's new release stores users in SQLite and signs them in with their Google accounts. Create the database with the right ownership, register an OAuth client, configure the app's secrets safely, then fix the ops team's Python report script.

Intermediate–Advanced~15 minsqlite3 · Google OAuth · Python · systemd3 randomized configsPart 3 of 3
What this demonstrates: wiring an app to its data and identity provider in production: file ownership for SQLite, OAuth 2.0 client and consent-screen setup, secrets in a root-only environment file loaded by systemd, and a bit of Python scripting for operations. Continues from Lab 14 (HTTPS is already working through Cloudflare).
